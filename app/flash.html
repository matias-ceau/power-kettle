Flash firmware

Install the Power Kettle firmware on an ESP32-C3 straight from the browser.

Steps

  1. Use desktop Chrome (or Edge).
  2. Plug the ESP32-C3 into the computer with a USB-C cable.
  3. Click Install and choose the C3's serial port.
This browser cannot flash over USB. Use desktop Chrome or Edge. Flashing needs a secure (https) page.

Android Chrome may not support flashing. Use a desktop computer.

If the port does not show up, hold BOOT while plugging the board in, then try again.
